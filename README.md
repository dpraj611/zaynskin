# 🌿 Zayn's Skin & Wellness Clinic  

✨ A mobile-first website built for **Zayn's Skin & Wellness Clinic** — blending clean design with modern web practices.  
Think of it as the digital lounge where skincare meets tech.  

---

## 🚀 Features  
- 📱 **Mobile-first** design (because 90% of us browse on phones anyway)  
- 👨‍⚕️ Doctor profile & services neatly presented  
- 📅 Appointment booking (because glowing skin can’t wait)  
- ⚡ Deployed with **Netlify CI/CD** for instant updates  

---

## 🛠️ Tech Stack  
- 🏗️ **HTML5**  
- 🎨 **CSS3 / Tailwind**  
- ✨ **JavaScript**  
- 🌐 **Netlify** for hosting
